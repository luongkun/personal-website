# Personal Website

Trang web portfolio cá nhân — xây dựng bằng HTML/CSS/JavaScript thuần.

## Cấu trúc

```
personal-website/
├── index.html      # Trang chính
├── css/style.css   # Styles
└── js/main.js      # Render kỹ năng & dự án
```

## Chạy local

Mở trực tiếp `index.html` trong trình duyệt, hoặc:

```bash
npx serve .
```

## Deploy

Repo này có thể deploy miễn phí qua **GitHub Pages** (Settings → Pages).
